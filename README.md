# 🩺 Здоровье — персональный медицинский дашборд

PWA-приложение для просмотра медицинской истории на телефоне, планшете и ПК.

> **Безопасность.** Репозиторий публичный, но содержит **только код и зашифрованные файлы (`*.enc`)**.
> Медицинские документы и база данных хранятся только на ПК владельца и публикуются исключительно
> в зашифрованном виде (AES-256-GCM, ключ из пароля). Без пароля данные не читаются.

## Структура

```
app/
├── src/                  приложение (React + TypeScript + Tailwind)
├── public/data/          только зашифрованные данные *.enc
├── scripts/
│   ├── check-public.mjs  защита от публикации открытых данных
│   └── guard/            правила защиты и тесты
├── .githooks/pre-commit  проверка перед каждым коммитом
└── .github/workflows/    автопубликация на GitHub Pages (с повторной проверкой)
```

## Команды

| Команда | Назначение |
|---|---|
| `npm install` | установка зависимостей (один раз) |
| `npm run setup-hooks` | подключение проверки перед коммитом (один раз после клонирования) |
| `npm run dev` | локальный запуск для разработки |
| `npm test` | автотесты |
| `npm run build` | сборка в `dist/` |
| `npm run guard:repo` / `guard:dist` | ручная проверка репозитория / сборки на открытые данные |

Подробная инструкция по обслуживанию — [MAINTENANCE_GUIDE.md](MAINTENANCE_GUIDE.md).
